# Homologação Santander Pix

Pendências antes de promoção de maturidade:

1. autenticar em homologação com Client ID/Secret e certificado reais;
2. criar Pix Cob com txid válido;
3. consultar a cobrança criada;
4. remover cobrança ativa;
5. validar credencial inválida e certificado inválido/expirado;
6. confirmar limites/rate limit e comportamento de erros;
7. registrar evidência operacional antes de alterar `IMPLEMENTED` para estado superior.
