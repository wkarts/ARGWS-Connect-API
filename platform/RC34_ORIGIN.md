# Platform Foundation Origin

A camada `platform/` foi integrada a partir da foundation **Connect-API-Platform v1.0.0-rc.34**.

Esta versão de origem é apenas referência da foundation. O versionamento canônico deste repositório continua sendo o `VERSION` da raiz do **Connect|API Engine** e todo release/deploy deve seguir os workflows e regras do repositório raiz.

Não criar VERSION, changelog de release independente ou workflow de release dentro de `platform/`.
