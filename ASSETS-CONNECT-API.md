# Connect|API — Runtime & Future Assets

A identidade visual pública do produto é **Connect|API**.

## Assets canônicos

- `public/branding/connect-api/core/` — Connect|API principal
- `public/branding/connect-api/docs/` — Connect|API DOCs
- `public/branding/connect-api/pbx/` — Connect|API PBX
- `public/branding/connect-api/voip/` — Connect|API VOIP

Cada conjunto contém PNG, SVG e JPEG light/dark quando aplicável.

## Compatibilidade

Arquivos com nomes legados `argws-connect-*` permanecem apenas como aliases de caminho para evitar quebra de runtime já compilado. O conteúdo visual desses arquivos foi substituído pela identidade Connect|API. Novas implementações devem usar os paths canônicos acima.

## Regra

Não adicionar novamente logos ou wordmarks antigos em `public/`, `manager/` ou novos módulos. Produtos derivados devem seguir o padrão `Connect|API <MÓDULO>`.
