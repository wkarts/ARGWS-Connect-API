# Connect|API v1.2.1 — suspensão temporária da transcrição fora do develop principal

Esta correção suspende transcrição e ditado em produção, canonical, homologação, CloudPanel, Dockge, Compose genéricos e nos canais Fersoft develop e production. Apenas o `deploy/develop/` principal mantém os workers e a interface de voz. A release estável não publica uma nova imagem de worker.

Nos demais deployments, o Compose remove os workers e força `SPEECH_ENABLED`, `TRANSCRIPTION_ENABLED`, `DICTATION_ENABLED` e `MANAGER_FEATURE_TRANSCRIPTION` a `false`, mesmo quando o `.env` antigo ainda contém `true`. O Manager oculta a página, o painel de configurações e os botões de transcrição e ditado. A API desabilitada deixa de iniciar o download do modelo durante a inicialização.

## Atualização de uma VPS já instalada

1. Preserve o `.env`, os segredos e `./volumes/*`. Substitua o Compose da stack pelo arquivo desta release e atualize a imagem da API/Manager conforme seu canal.
2. Retire `transcription` de `COMPOSE_PROFILES` e deixe as quatro flags acima em `false` no `.env` persistido para manter a configuração legível. O Compose novo também as força a `false` no processo da API.
3. No diretório da instalação, faça o pull e recrie os serviços usando o Compose atualizado:

   ```bash
   docker compose --env-file .env -f compose.yaml pull
   docker compose --env-file .env -f compose.yaml up -d --pull never --remove-orphans
   docker compose --env-file .env -f compose.yaml ps -a
   ```

   No CloudPanel use `-f docker-compose.yml`. No Dockge ou em outro painel, ative a remoção de containers órfãos; se não houver essa opção, pare e remova apenas os containers antigos de transcrição e ditado dessa stack.
4. Confira que a API e os serviços de mensagens seguem saudáveis e que os workers antigos não aparecem no `ps -a`. A publicação da release por si só não desliga containers já em execução nas VPS.

Não execute `docker compose down -v` nem apague bancos, filas ou `./models`. O modelo já baixado pode ficar em disco sem consumir a memória do worker.

O [guia de implantação](../../deploy/README.md) e o [guia de voz](../guides/speech.md) descrevem a seleção atual dos canais e a retomada segura do deploy.
